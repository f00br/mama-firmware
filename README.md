# MAMA firmware mirror

This repository holds the exact firmware packages for the M-VAVE FM-1 that the MAMA app verified on its test bench.
MAMA is an Android DAW and firmware manager for the FM-1, and its firmware library pins every package by SHA-256.
Authors publish new versions, and The Firmware Hub keeps only the latest one, so older download links stop working.
This mirror keeps those exact bytes reachable, so an install MAMA verified keeps working after the author or the Hub moves on.

## What is here

- Release [`packages`](https://github.com/f00br/mama-firmware/releases/tag/packages): one file per firmware, named `<hub_id>--<original file name>`. The bytes are identical to the author's release; check them against `sha256` in `manifest.json`.
- Release [`sources`](https://github.com/f00br/mama-firmware/releases/tag/sources): for every GPL, LGPL, AGPL or MPL firmware, the source of that exact version as `<hub_id>--source.tar.gz`, taken from the author's GitHub tag or commit. Where no tag or commit for that exact build could be resolved, the manifest and the table below link the author's repository instead.
- `manifest.json` (schema `mama.firmware-mirror/1`): every firmware in the MAMA library, with its licence, SHA-256, size, mirror link, original link and whether that link still answered, the author's own release asset when one exists, and how its source was resolved.
- `not-mirrored.txt`: firmwares MAMA lists but this mirror does not carry. MAMA keeps sending users to the author's own link for those.

## Licences

Each file keeps its author's licence; nothing here is relicensed. The licence of each package is listed in `manifest.json` and in the table below. The full licence text is in the author's repository and, for copyleft firmwares, inside the source archive next to the package.
Only firmwares whose licence allows redistribution (GPL, LGPL, AGPL, MPL, MIT, Apache, BSD, ISC, CC0, Unlicense) are mirrored.

## Removal

If you are an author and want a file taken down or corrected, open an issue in this repository and it will be handled.
